# 釐清問題

時間性查詢中「最近」的具體時間長度為何？（例句「我最近買過什麼飲料？」；目前僅定義資料來源優先序：內容時間優先、為空時用上傳時間，但「最近」涵蓋多久未量化）

# 定位

Feature：「自然語言詢問」的規則「詢問含時間條件時，系統以內容時間過濾，內容時間為空的照片以上傳時間過濾」中，「最近」對應的過濾區間

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 最近 30 天內 |
| B | 最近 7 天內 |
| C | 最近 90 天內 |
| D | 不固定：由 LLM 依問題語意自行決定時間區間 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- 功能「自然語言詢問」：時間過濾規則的可驗證性與 Example 的邊界資料設計
- 測試：時間邊界案例（剛好在區間內/外）

# 優先級

Medium
- 影響時間性查詢的可驗證性與邊界測試，不阻礙主流程
