# 釐清問題

上傳照片時，是否限制檔案格式與大小？（規格未提及任何前置驗證條件）

# 定位

Feature：「上傳照片」的前置條件（目前該功能沒有任何前置條件規則）

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 不限制，任何檔案都受理（交由 VLM 處理結果決定） |
| B | 限制為常見圖片格式（如 JPEG/PNG），不限大小 |
| C | 限制格式並設定大小上限（需指定上限值） |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- 功能「上傳照片」：是否新增前置條件規則與「操作失敗」Example
- 測試：非圖片檔、超大檔案的類別邊界 Example（B4 類別邊界、B5 錯誤處理）
- API 設計：FastAPI 上傳端點的驗證行為

# 優先級

Medium
- 影響前置條件完整性與錯誤處理測試，不阻礙核心流程定義

---
# 解決記錄

- **回答**：限制為常見圖片格式（如 JPEG、PNG），非圖片格式上傳失敗；不設大小上限（對應本項目選項 B）
- **更新的規格檔**：spec/features/上傳照片.feature
- **變更內容**：新增前置條件規則「上傳檔案必須為常見圖片格式」與 1 個 Example（非圖片格式 → 操作失敗、照片數量為 0），並註明不設大小上限
