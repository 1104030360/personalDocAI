# 釐清問題

「根據問題類型決定走 vector semantic search 或 PostgreSQL metadata search」中，「問題類型」的分類標準為何？規格的兩個例句（「我最近買過什麼飲料？」、「有哪些在 Target 拍的收據？」）各對應哪條檢索路徑？

# 定位

Feature：「自然語言詢問」的規則「詢問時，系統根據問題類型決定走 vector semantic search 或 PostgreSQL metadata search」

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 由 LLM 判斷：語意/內容描述型問題走 vector search，明確條件過濾型（地點、類別、時間）走 metadata search |
| B | 規則式判斷：問題中出現 metadata 欄位對應的關鍵字（如地點、類別）即走 metadata search，否則走 vector search |
| C | 兩路皆執行後合併結果（不做二選一路由） |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- 功能「自然語言詢問」：路由規則的定義與 LangGraph workflow 的分支條件
- 測試：兩個規格例句的路由歸屬 Example（缺此答案該規則無法產生任何 Example）
- 依賴 metadata 欄位定義（metadata search 可用的過濾條件）

# 優先級

High
- 路由是本專案核心 workflow 的關鍵決策點，未定義則核心功能規則無法完成定義與驗證

# 依賴/組合

- 依賴「Photo_metadata的具體欄位為何」；建議與「自然語言詢問_無法判斷問題類型時如何處理」組合釐清
