# 釐清問題

當系統無法判斷問題類型（既不明確屬於語意查詢、也不屬於 metadata 條件查詢）時，應如何處理？

# 定位

Feature：「自然語言詢問」的路由規則之異常分支（規格僅描述二選一路由，未定義無法分類的情況）

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 預設走 vector semantic search |
| B | 預設走 PostgreSQL metadata search |
| C | 兩路皆執行並合併結果 |
| D | 回覆使用者無法理解問題，請重新提問（操作失敗） |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- 功能「自然語言詢問」：需新增一條 fallback 規則與對應 Example
- LangGraph workflow：路由節點的 default 分支設計
- 測試：異常輸入的邊界 Example（B5 錯誤處理）

# 優先級

Medium
