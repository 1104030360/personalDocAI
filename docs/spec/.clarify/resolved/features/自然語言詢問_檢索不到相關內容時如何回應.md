# 釐清問題

當檢索（vector semantic search 或 metadata search）找不到任何相關內容時，系統應如何回應使用者？

# 定位

Feature：「自然語言詢問」的規則「詢問後，系統將檢索到的內容交給 LLM 產生回答」之空結果分支

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 仍交給 LLM，由 LLM 產生「查無相關照片」類的自然語言回覆 |
| B | 不經 LLM，直接回覆固定訊息（如：查無相關照片） |
| C | 視為操作失敗，回傳錯誤 |
| Short | 提供其他簡短答案（<=5 字）|

# 影響範圍

- 功能「自然語言詢問」：需新增空結果規則與 Example
- 測試：空資料狀態的邊界 Example（Given 無任何照片時詢問）
- 回答品質：避免 LLM 在無檢索內容時憑空編造（hallucination）的行為定義

# 優先級

Medium
- 影響錯誤/邊界行為與測試完整性，不阻礙主流程

# 依賴/組合

- 無前置依賴，可獨立釐清

---
# 解決記錄

- **回答**：A - 仍交給 LLM，由 LLM 產生「查無相關照片」類的自然語言回覆，並約束不得編造照片內容
- **更新的規格檔**：spec/features/自然語言詢問.feature
- **變更內容**：新增規則「檢索不到任何相關內容時，系統回覆查無相關照片」與 1 個 Example（Given 系統中沒有任何照片 → 詢問 → 獲得查無相關照片的回覆）
