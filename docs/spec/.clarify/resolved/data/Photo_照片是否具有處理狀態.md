# 定位

ERM：Photo 實體的生命週期與狀態（A6）；同時影響功能「上傳照片」的後置條件時點

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 同步處理：上傳完成即代表文字、metadata、向量皆已儲存，不需要狀態欄位 |
| B | 非同步處理：上傳先受理，背景處理，Photo 需要狀態欄位（如：處理中、完成、失敗） |
| Short | 提供其他簡短答案（<=5 字）|
