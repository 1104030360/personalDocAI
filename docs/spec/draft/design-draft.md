這個專案會做成一個簡單的 Multimodal RAG / Visual Memory RAG：使用者透過 FastAPI 上傳照片，系統先利用 VLM 理解圖片內容並轉成文字與結構化 metadata，再透過 LangChain 將內容建立成 Document、產生 embeddings，並使用 PostgreSQL + pgvector 儲存圖片資訊、metadata 與向量；之後使用者可以直接用自然語言詢問，例如「我最近買過什麼飲料？」或「有哪些在 Target 拍的收據？」，系統會使用 LangGraph 建立簡單的 retrieval workflow，根據問題類型決定走 vector semantic search 或 PostgreSQL metadata search，最後把檢索到的內容交給 LLM 產生回答。整個專案的重點是用一個小型、可實際 demo 的 backend 展示 FastAPI + PostgreSQL/pgvector + VLM + LangChain RAG + LangGraph workflow 的整合能力。FastAPI 適合建立 Python API；LangChain 提供 retrieval、embedding 與 vector-store abstraction；LangGraph 則負責 stateful workflow 與 routing；pgvector 可以直接在 PostgreSQL 裡做 vector similarity search。
