## 遇到的問題與解法

- **問題**：第一次跑驗收 4／5 時 curl 回 HTTP 000，但 uvicorn log 顯示「Application startup complete」——是**執行工具的沙箱**擋住了對臨時服務的連線，不是程式問題。**解法**：查 log 確認服務本身健康後，改以非沙箱模式重跑同一組指令，全部通過。此問題只影響自動化驗證環境，使用者手動操作不會遇到。
