1. **`get_folder` 查無時會不會回一列 `count=0`**（聚合查詢常見陷阱）：計畫 SQL 帶 `GROUP BY f.id`，WHERE 無匹配時分組數為零 → `fetchone()` 得 `None`；`test_取得不存在的資料夾回傳_None` 實測通過。無需改動。
2. **改動面控制**：`git diff` 的刪除行僅 5 行且逐行核對全屬 Phase 15（docstring 舊句、舊 `PHOTO_COLUMNS`、舊 INSERT 欄位列），本輪零刪除、零觸碰既有路徑——83 個既有測試零紅的原因成立。
3. **f-string 無插值（潛在 F541）**：專案無任何 lint 設定，依計畫自註照原文保留；日後若導入 ruff 再處理。
