### 7.1 一次性：讓 iPhone 信任這台 Mac 的憑證

> `certs/cert.pem`／`key.pem` 已經產好（SAN 含 10.0.0.34／localhost／127.0.0.1），但 **`mkcert -install` 還沒執行**，所以現在還沒有任何裝置信任它。
> **現有憑證不必重簽**：被信任的是「根憑證」，`mkcert -install` 晚一步做，先前簽出來的憑證一樣會被回溯認可（已用 openssl 驗證同一張 leaf 由同一把 CA 簽發）。

```bash
cd /Users/linjunting/personalDocAI && source .venv/bin/activate

# ① 讓這台 Mac 信任 mkcert 的根憑證（會問開機密碼）
mkcert -install

# ② 打開根憑證所在的資料夾
open "$(mkcert -CAROOT)"        # ＝ ~/Library/Application Support/mkcert
```
③ 把資料夾裡的 **`rootCA.pem`** 用 **AirDrop** 傳到 iPhone（`rootCA-key.pem` 不要傳）。
④ iPhone：**設定** →（最上方會出現）**已下載描述檔** → **安裝** → 輸入解鎖密碼 → 右上 **安裝** → 再 **安裝**。
> 那一列若沒出現（描述檔等待安裝有時效，逾時就從最上方消失）：**設定 → 一般 → VPN 與裝置管理**，在「描述檔」底下找到它再安裝；真的不見了就重新 AirDrop 一次。
⑤ iPhone：**設定 → 一般 → 關於 →（拉到最底）憑證信任設定** → 把 **mkcert …** 那一列的開關打開 → **繼續**。
> ⚠ 少了第 ⑤ 步 Safari 仍然會擋，而且錯誤訊息長得像「網路怪怪的」，很難聯想到憑證。

**什麼時候才真的需要重簽憑證**：只有**本機區網 IP 變了**的時候（憑證把 IP 寫死在 SAN 裡，現在綁的是 10.0.0.34）。換 Wi-Fi、路由器重新配發 IP 之後，`ipconfig getifaddr en0` 若不再是 10.0.0.34，就重跑一次：

```bash
mkdir -p certs      # certs/ 已入 .gitignore，重新 clone 後不存在
mkcert -cert-file certs/cert.pem -key-file certs/key.pem \
  $(ipconfig getifaddr en0) localhost 127.0.0.1
```
（重簽 leaf 不必動 iPhone——根憑證沒換，手機那邊的信任照舊。）

### 7.2 每次驗收：啟動與開頁

```bash
cd /Users/linjunting/personalDocAI && source .venv/bin/activate
ipconfig getifaddr en0          # 記下區網 IP，例如 10.0.0.34

uvicorn app.main:app --host 0.0.0.0 --port 8000 \
  --ssl-keyfile certs/key.pem --ssl-certfile certs/cert.pem
```
電腦瀏覽器開：**`https://<區網IP>:8000/ui/camera-desk.html`**
（也可以從 `https://<區網IP>:8000/ui/upload.html` 點「用手機拍」進去。
**不要用 `https://localhost:8000`**——那樣 QR 的 IP 只能靠 UDP 偵測猜，猜錯就掃不到。）

手機與電腦必須在**同一個 Wi-Fi**，且不是「訪客網路」（訪客網路會把裝置互相隔離，一定配對失敗）。

### 7.3 驗收步驟與預期結果

| # | 操作 | 預期 |
|---|---|---|
| 1 | 開桌面頁 | 左欄出現 QR＋一行 `https://<區網IP>:8000/ui/camera-phone.html?token=…`；狀態列「等手機掃碼…」；四顆遙控鈕**灰的**（還沒有畫面） |
| 2 | iPhone 相機 App 對著 QR | 跳出橫幅 → 點開 → Safari 開本系統手機頁 |
| 3 | Safari 問「要允許使用相機嗎」→ **允許** | 手機出現後鏡頭取景畫面，下方三顆按鈕亮起，狀態「取景中。對準要拍的東西，兩邊都能按快門。」 |
| 4 | 看電腦 | **1 秒內**出現手機的即時畫面（連續影像，不是每 2 秒一張）；狀態列綠點「即時預覽中——快門兩邊都能按」；四顆鈕亮起 |
| 5 | 電腦按「切換鏡頭」 | 手機切前鏡頭，電腦畫面跟著換（畫面不會中斷） |
| 6 | 手機按「切換鏡頭」 | 切回後鏡頭，效果同上 |
| 7 | 「開閃光」 | iPhone Safari 多半**不支援**：按鈕自動變灰＋電腦顯示「這支手機的瀏覽器不支援閃光，請改用手電筒或找亮一點的地方」。**這是預期的優雅降級，不是 bug**（計畫「已知限制」第一條）。Android Chrome 則應該真的亮手電筒 |
| 8 | 對準一張收據，**電腦**按「按快門」 | 手機顯示「拍好了，上傳中…」→ 電腦狀態列「手機正在上傳這一張…」→ 等真模型看圖（**實測 2〜5 分鐘／張**）→ 電腦跳出**抽屜彈窗**、手機顯示「已送出——到電腦上繼續。」 |
| 9 | 電腦上完成三關彈窗鏈 | 抽屜（採用建議／改選／自建／稍後再說）→ 實體窗 → 待辦窗（VLM 有抓到待辦才開）；與一般上傳頁一模一樣 |
| 10 | **手機**按「按快門」 | 與第 8 步完全相同（彈窗**只在電腦**跳） |
| 11 | 電腦按「重拍」 | 結果卡片回到「已回到取景」，手機文案回到取景提示；**已入庫的那張不會被刪**（本專案沒有刪除照片） |
| 12 | 關掉電腦那一頁 | 手機立刻顯示「配對已結束（電腦那一頁關掉或超過 10 分鐘）。請重新掃描電腦上的 QR。」，快門變灰 |
| 13 | 到瀏覽頁「待決定／資料夾」分頁 | 剛剛拍的照片在該在的地方，縮圖看得到 |

### 7.4 常見失敗排查

| 症狀 | 多半是 | 怎麼修 |
|---|---|---|
| 手機開頁面說「這個瀏覽器不給用鏡頭…」 | 網址是 `http://` 或憑證沒被信任 | 確認網址 `https://` 開頭；重做 §7.1 的 ④⑤（**第 ⑤ 步最常漏**） |
| Safari 顯示「此連線非私人連線」 | 根憑證沒裝／沒開「完全信任」，或**區網 IP 換了**（憑證 SAN 對不上） | 先確認 §7.1 ④⑤ 都做了；再對照 `ipconfig getifaddr en0` 與網址是否一致，不同就照 §7.1 末尾重簽 leaf（不必動 iPhone） |
| iPhone 設定裡找不到「已下載描述檔」 | 描述檔等待安裝逾時，從最上方消失了 | 設定 → 一般 → **VPN 與裝置管理** → 描述檔底下找它；真的不見就重新 AirDrop |
| QR 掃了跳出的網址是 `localhost` | 桌面頁是用 `localhost` 開的 | 改用 `https://<區網IP>:8000/ui/camera-desk.html` 重開，重新掃新的 QR |
| 手機頁開得起來、電腦卻一直「等手機掃碼…」 | 手機連到不同 Wi-Fi，或 token 過期（>10 分鐘） | 確認同一個 Wi-Fi；重新整理電腦那一頁拿新 QR |
| 電腦顯示「手機已連上」但畫面一直不出來 | 路由器開了 AP 隔離／訪客網路，WebRTC 直連被擋 | 換成一般（非訪客）Wi-Fi；兩台都不要用 VPN |
| 畫面出現後又斷，顯示「畫面中斷了」 | 手機鎖屏或切到別的 App | 手機回到該頁面、必要時重新整理（會自動重新協商） |
| 按快門後很久沒反應 | 真模型看圖本來就慢（實測 2〜5 分鐘／張） | 等；手機狀態列會停在「拍好了，上傳中…」，電腦狀態列會顯示「手機正在上傳這一張…」 |
| 快門後顯示「沒有存成功（HTTP 422）」 | VLM 看不懂這張（太暗／太糊） | 這是既有語意：**什麼都沒存**。重拍一張清楚的 |
| 快門後顯示 HTTP 404 | 配對過期（>10 分鐘）或電腦那頁關過 | 重新整理電腦頁、重新掃 QR |
| `uvicorn` 說找不到 `certs/key.pem` | 沒在專案根目錄啟動 | `cd /Users/linjunting/personalDocAI` 後再啟動 |
