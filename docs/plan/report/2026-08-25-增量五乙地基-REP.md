## 5. 遇到的問題與解法

1. **併行審查 vs 進行中實作**：reviewer 審 A phase 時工作樹會出現 B phase 的半成品——
   每位 reviewer 都以 mtime／md5／快照相減證明自己審的檔未被污染，並把「工作樹另有上游痕跡」
   明確標註不算走私。將來 commit 時**必須路徑限定 `git add`**（各 task report 已列出每 phase 的檔案清單）。
2. **絕對顆數 vs 實際路徑**：計畫檔內的絕對數字假設「乙先行」路徑，實際交錯執行後以
   「本 phase 新增幾顆」對帳（總覽 §9 明文授權），全程吻合。
