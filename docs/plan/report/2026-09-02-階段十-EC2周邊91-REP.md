## 5. 遇到的問題與怎麼解決

- **`docker login` 到 ECR 逾時**：host 與容器對 ECR `/v2/` 都 0.5 秒回 401（＝連得到），只有 Docker 引擎本身（走 Docker Desktop 內建代理 `http.docker.internal:3128`）第一次卡住；重試一次就 `Login Succeeded`。是暫時性的，不是設定問題。
- **`latest` tag 被 zsh 吃掉**：在 zsh 互動 shell 裡 `"$ECR_URI:latest"` 的 `:l` 是「轉小寫」修飾子，展開成 `<uri>atest` → docker 去推一個叫 `personaldocai-workeratest` 的 repo 而失敗；`bb3921a` 那個 tag 沒事（`:$SHA` 不是修飾子）。改用 `${ECR_URI}:latest` 重推成功。計畫檔的寫法在 bash 腳本裡沒問題，之後照抄到 zsh 要注意。
- **實作者在計畫檔留下兩條錯的自述**（§4.10 ③ 字元集「太弱」——其實 controller 已依 R19 改成 `[A-Za-z0-9_]`；`.dockerignore` 「沒有 `deploy/`」——Phase 90 早加了）：controller 在 §9 補了更正，免得日後有人照著做白工。
