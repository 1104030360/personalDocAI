## 遇到的問題與解法

1. **計畫自我衝突（本 phase 唯一 finding）**：驗收項 8 的 grep（查 `from app.core.config import`）必然命中計畫步驟 3 自己指定寫入 config.py 的那行**警告註解**，永遠印不出預期的 `OK`。裁決：規則實質未違反（排除註解行後零命中；`test_測試期間DATA_DIR指向暫存目錄` PASSED 為活證據），屬計畫檢查指令的缺陷——已修正計畫該驗收項（grep 加 `| grep -v ":[0-9]*:#"` 並註明緣由），修正後指令實測印出 `OK：全部走 config.XXX`。
2. **紅燈訊息與計畫措辭不同**：實際為 `ImportError: cannot import name 'storage_service' from 'app.services'`（`app/services/` 是有 `__init__.py` 的套件、測試用 from-import 形式），非 `ModuleNotFoundError`。裁決：根因相同（模組不存在）、計畫原文寫「訊息類似」，視為符合，不改計畫。
3. **Pillow 實裝 12.3.0**（計畫舉例 11.x）：滿足 `>=10` 約束，正常版本推進，無需處理。
