## 遇到的問題與解法

- **問題**：計畫假設 5432 可用，實際被別的專案佔用。**解法**：並存於 5433（詳上）；否決了「停用 @14」（破壞他人專案）與「pgvector 對 @14 source build」（brew 升級後 extension 會失蹤的隱形地雷）。
- **注意事項（已寫進文件）**：`PGPORT=5433` 會讓互動 shell 的 `psql` 預設連 5433；要連 @14 需 `psql -p 5432`。其他專案的伺服器程式不讀 zshrc，不受影響。
