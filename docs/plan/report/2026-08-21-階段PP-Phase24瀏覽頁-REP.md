## 遇到的問題與解法

1. **`curl -I`（HEAD）對 `/` 回 405**：FastAPI 的 `@app.get` 不自動註冊 HEAD。瀏覽器實際走 GET（307 正確）；已校準計畫檢查指令為 GET 版並註記原因。
2. 一批 shell 指令因沙箱 PATH 遺失 curl/git 等（偶發）→ 改絕對路徑重跑，全過。
