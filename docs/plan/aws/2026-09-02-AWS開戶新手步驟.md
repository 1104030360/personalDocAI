# AWS 開戶新手步驟（Phase 82）

給還沒用過 AWS 的人。做完＝帳號開好、不會被默默扣卡、這台 Mac 打得通 `aws`。

**今天不要做：** 建 S3、建 SQS、開 EC2、按 Upgrade to Paid、開 Organizations／Control Tower。那些會燒點數或把 Free plan 升成付費。

查證日期：2026-09-02。來源見文末。

---

## 你要先準備

| 東西 | 為什麼 |
|---|---|
| 沒用過的 email | 註冊收驗證信。Gmail 可用 `你的名字+aws@gmail.com` |
| 手機 | 簡訊驗證；稍後綁 MFA |
| 信用卡或簽帳卡 | **一定要填**。Free plan **升 Paid 之前不會扣使用費**；開戶時可能出現約 **USD $1** 驗證（官方說驗證後退回，銀行常見 3〜5 天） |
| Homebrew | 這台 Mac 用來裝 CLI |

開戶當天就開始算 **6 個月**。你已確認 ★G1，可以開。

---

## 免費方案是什麼（2025-07-15 之後的新帳號）

開戶選 **Free**，不是舊的「12 個月某服務免費額度」。

- 立刻給 **USD $100** 點數；做完 Console「Explore AWS」活動最多再 +$100（合計最多 $200）
- 點數 **開戶滿 12 個月失效**
- Free plan 結束條件（先到者）：**滿 6 個月**，或**點數用完**
- 結束後帳號會關；資料留 **90 天**，這段期間可升 Paid 救回
- **升了 Paid 不能降回 Free**
- 加入 Organizations／Control Tower ＝ **自動升 Paid，點數立刻作廢**
- 本專案區域固定 **東京 `ap-northeast-1`**

免費額度入口：<https://aws.amazon.com/free/>

本專案會用到、之後才建、都吃點數：S3（寄物櫃）、SQS（兩條佇列）、EC2（工人，更後面、要再過 ★G2）。**今天一個都不要開。**

## 步驟

做完一項打勾。卡關把畫面／錯誤貼回來（**不要貼 Access key 或密碼**）。

### 1. 開帳號

1. 開 <https://aws.amazon.com/free/> → **Create a free account**（或 Create an AWS Account）。
2. 填 email、帳號名稱（例如 `personaldocai`）、密碼。帳號類型選 **Personal** 即可。
3. **選方案那一頁選 Free，不要選 Paid。**
4. 填卡與手機驗證。支援方案選 **Basic – Free**。
5. 進 Console 後，右上角區域改成 **Asia Pacific (Tokyo) `ap-northeast-1`**。

選錯 Paid：官方寫明不能降回 Free，換 email 重開比較乾淨。

### 2. 幫 root 開 MFA，然後不要再用它日常登入

root ＝註冊那個 email，權限無法限制。

1. 右上角帳號選單 → **Security credentials** → **Assign MFA device**。
2. 選 **Authenticator app**，手機掃 QR，連續輸入兩組動態碼。
3. **登出 root。** 下一步建完管理者後，日常改用那個使用者。

**不要**幫 root 建 Access key。

### 3. 第一天就建預算（不可挪後）

Free plan 不扣卡；真正的風險是**點數燒完 → 關帳 → 資源消失**。每月 $5 是刻意設低：正常用量遠低於它，寄信＝有東西不對。

仍用 **root** 做這一步（少數該用 root 的事）：

1. 右上角 → **Billing and Cost Management** → 左側 **Budgets** → **Create budget**。
2. **Customize (advanced)** → **Cost budget**。
3. 名稱 **`personaldocai-budget`**（逐字）、Period **Monthly**、Recurring、Fixed、金額 **5 USD**。
4. 加兩條警報，收信人都填你的 email：

   | 觸發 | 門檻 | 意思 |
   |---|---|---|
   | **Actual** | 80% | 這個月已花到 $4 |
   | **Forecasted** | 80% | 預測月底會到 $4（新帳號前幾週可能還沒預測，正常） |

5. **Create budget。**
6. 回到 Billing → **Account**（或帳號設定）→ **IAM user and role access to billing information** → **Activate**。之後管理者才能在 Console 看帳單。

可順手領點數：Console 首頁 **Explore AWS** 若有「建一個有警報的 Budget」活動，做完通常 +$20。**不要**為了另外 +$20 去開 RDS／Lambda／Bedrock。

只寄信、不設 budget action 的預算：**免費**。

### 4. 這台 Mac 裝 AWS CLI v2

```bash
brew install awscli
aws --version
```

開頭必須是 `aws-cli/2.`。若是 `1.`，把舊的卸掉再裝。

官方另一種裝法（不用 brew）：<https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html>（macOS 用官方 install script 或 `.pkg`）。這台機器有 Homebrew，用 brew 即可。

### 5. 建「人用」管理者，並設好 CLI

再用 **root** 登入 Console → 搜尋 **IAM** → **Users** → **Create user**。

1. 名稱：`personaldocai-admin`
2. 勾 **Provide user access to the AWS Management Console** → **I want to create an IAM user**（不要選 Identity Center）→ 自訂密碼。
3. **Attach policies directly** → 勾 **`AdministratorAccess`** → Create。
4. 建議：這個 user 也綁 MFA（Security credentials → Assign MFA device）。
5. 同一頁 **Access keys** → **Create access key** → 用途選 **Command Line Interface (CLI)** → 建立。
6. **Secret 只顯示一次。** 先不要關視窗，立刻在終端機：

```bash
aws configure
```

依序填：Access key ID、Secret、Default region **`ap-northeast-1`**、輸出格式 **`json`**。

這把 key 只放在 `~/.aws/credentials`（給你打 `aws` 指令）。**不要**貼進聊天、截圖、commit。

然後**登出 root**，之後用 `personaldocai-admin` 登 Console。

### 6. 確認連得上

```bash
aws sts get-caller-identity
```

應看到 12 位 `Account`，以及 `Arn` 結尾是 `user/personaldocai-admin`。

把 **Account（12 位數字）** 記在自己的密碼管理器。文件與聊天只寫「我的 account id」，不要把數字貼進 repo。

## 不要做

- 開 Organizations／Control Tower
- Upgrade to Paid／付費 Support
- 開 EC2「先試試看」
- 建第二個區域的資源
- 把 Access key 寫進任何會進 git 的檔

終端機如果 `source` 過專案 `.env`，先執行：

```bash
unset AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY
```

否則環境變數會蓋掉 `aws configure`，CLI 會用錯鑰匙。
