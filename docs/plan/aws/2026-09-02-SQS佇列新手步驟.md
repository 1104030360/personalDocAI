# SQS 佇列新手步驟

給第一次建 SQS 的人。做完＝東京有兩條**標準佇列**：一條叫工人做事，一條把「做完了」傳回本機。

**建議先做完 [S3](./2026-09-02-S3寄物櫃新手步驟.md)。** 這份只建佇列，不改產品碼。

查證日期：2026-09-02。來源見文末。

---

## 這是什麼

SQS（Simple Queue Service）＝ AWS 的訊息佇列。一邊放紙條、另一邊拿紙條，兩邊不必同時在線。

S3 負責放大檔（圖、JSON）。SQS **只放指路的紙條**，永遠不放影像位元組。

順序鐵律：**東西先成功寫進 S3，才發 SQS 訊息。** 反過來，對方會去拿一個還沒寫完的檔。

| 佇列 | 誰放 | 誰拿 | 紙條內容 |
|---|---|---|---|
| `personaldocai-jobs` | 本機 | 工人 | `{"job_id":"...","s3_key":"documents/<id>/input.jpg"}` |
| `personaldocai-results` | 工人 | 本機 | `{"job_id":"..."}` |

---

## 三個設定先懂

| 名詞 | 白話 | 本專案值 |
|---|---|---|
| **Standard（標準）** | 便宜、可能重送同一則、不保證順序 | 兩條都用這個 |
| **FIFO** | 保證順序、保證一次，較貴 | **不要建**（佇列名也不准以 `.fifo` 結尾） |
| **可見度逾時 VisibilityTimeout** | 拿走後隱形幾秒；時間到還沒刪，紙條會再出現 | jobs **900 秒**、results **30 秒** |
| **長輪詢 ReceiveMessageWaitTimeSeconds** | 「沒有的話先等最多 N 秒」。AWS 上限 **20** | 兩條都 **20** |
| **保留期 MessageRetentionPeriod** | 沒人拿最多留多久 | **4 天**＝345600 秒（官方預設） |

jobs 設 900 秒：工人看多頁 PDF 可能好幾分鐘。太短＝還在做、紙條又出現＝同一份被做兩次。  
results 設 30 秒：本機只做「去 S3 拿結果＋刪訊息」，幾毫秒；設短一點，拿錯別人的紙條也能快還回去。

標準佇列是 **at-least-once**（至少送一次）＝同一則可能來兩次。程式之後必須冪等，建佇列這一步不用管。

## 先確認

```bash
aws sts get-caller-identity --profile personaldocai-admin --region ap-northeast-1
```

要用 **`personaldocai-admin`**。佇列名在「同一帳號＋同一區」內唯一，**不必全球唯一**（跟 S3 不一樣）。

---

## 1. 建兩條 Standard 佇列

漏寫 `FifoQueue`＝官方預設就是 Standard。不要自己加 `FifoQueue=true`。

```bash
aws sqs create-queue \
  --queue-name personaldocai-jobs \
  --profile personaldocai-admin \
  --region ap-northeast-1 \
  --attributes VisibilityTimeout=900,ReceiveMessageWaitTimeSeconds=20,MessageRetentionPeriod=345600

aws sqs create-queue \
  --queue-name personaldocai-results \
  --profile personaldocai-admin \
  --region ap-northeast-1 \
  --attributes VisibilityTimeout=30,ReceiveMessageWaitTimeSeconds=20,MessageRetentionPeriod=345600
```

成功各印一個 `QueueUrl`，長得像：

`https://sqs.ap-northeast-1.amazonaws.com/<帳號12碼>/personaldocai-jobs`

**程式之後用的是 URL，不是名字。** URL 含帳號 ID，只放 `.env`，不要貼進會進版控的文件。

同名再跑一次：佇列已存在時，屬性必須**完全相同**才會回同一個 URL；屬性不一樣會報錯。不要為了「改一下」重複 create。

---

## 2. 驗收

```bash
JOBS_URL=$(aws sqs get-queue-url --queue-name personaldocai-jobs \
  --profile personaldocai-admin --region ap-northeast-1 --query QueueUrl --output text)
RESULTS_URL=$(aws sqs get-queue-url --queue-name personaldocai-results \
  --profile personaldocai-admin --region ap-northeast-1 --query QueueUrl --output text)
echo "$JOBS_URL"
echo "$RESULTS_URL"

aws sqs get-queue-attributes \
  --queue-url "$JOBS_URL" \
  --attribute-names VisibilityTimeout ReceiveMessageWaitTimeSeconds MessageRetentionPeriod FifoQueue \
  --profile personaldocai-admin --region ap-northeast-1

aws sqs get-queue-attributes \
  --queue-url "$RESULTS_URL" \
  --attribute-names VisibilityTimeout ReceiveMessageWaitTimeSeconds MessageRetentionPeriod ApproximateNumberOfMessages \
  --profile personaldocai-admin --region ap-northeast-1
```

對就好：

| | jobs | results |
|---|---|---|
| VisibilityTimeout | `900` | `30` |
| ReceiveMessageWaitTimeSeconds | `20` | `20` |
| MessageRetentionPeriod | `345600` | `345600` |
| FifoQueue | **沒這個欄位** | 同左 |
| ApproximateNumberOfMessages | — | **`0`**（剛建好應該是空的） |

把兩個 URL 寫進 `.env`：

```
SQS_JOBS_QUEUE_URL=https://sqs.ap-northeast-1.amazonaws.com/12碼/personaldocai-jobs
SQS_RESULTS_QUEUE_URL=https://sqs.ap-northeast-1.amazonaws.com/12碼/personaldocai-results
```

## 可選：手動走一圈（證明自己聽得懂）

```bash
aws sqs send-message \
  --queue-url "$JOBS_URL" \
  --message-body '{"job_id":"smoke","s3_key":"documents/smoke/input.png"}' \
  --profile personaldocai-admin --region ap-northeast-1

aws sqs receive-message \
  --queue-url "$JOBS_URL" \
  --wait-time-seconds 5 \
  --profile personaldocai-admin --region ap-northeast-1
```

會拿到 `Body` 與 `ReceiptHandle`。刪掉要用**收據把手**（每次拿都不一樣），不是 message id：

```bash
aws sqs delete-message \
  --queue-url "$JOBS_URL" \
  --receipt-handle '剛才印出來的那一長串' \
  --profile personaldocai-admin --region ap-northeast-1
```

做完確認 jobs 也回到 0 則。不要把真的照片位元組貼進 `--message-body`。

---

## 不要做

- 建 FIFO（名字以 `.fifo` 結尾的那種）
- 建 dead-letter queue（死信佇列）
- 開 SSE-KMS 自管金鑰（佇列裡只有 `job_id` 這種字串）
- 把圖或 PDF 塞進訊息
- 現在開 EC2、現在改 `get_cloud_route()`

---

## 做錯怎麼拆

```bash
aws sqs delete-queue --queue-url "$JOBS_URL" \
  --profile personaldocai-admin --region ap-northeast-1
aws sqs delete-queue --queue-url "$RESULTS_URL" \
  --profile personaldocai-admin --region ap-northeast-1
```

刪掉之後 **60 秒內不能用同一個名字再建**（官方規定）。
