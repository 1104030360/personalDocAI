## 這是什麼

EC2（Elastic Compute Cloud）＝ AWS 上的一台虛擬電腦。本專案用它跑「看圖工人」：從 SQS 拿工作、去 S3 取圖、呼叫雲端 VLM、把 `result.json` 放回 S3、再丟一張紙條到 results 佇列。

它**不對外開門**。沒有網頁、沒有 SSH。本機永遠不連進這台機器；溝通只走 S3 + SQS。

```
本機 --(圖)--> S3 寄物櫃 <--(自己拿)-- EC2 工人
本機 --(紙條)--> SQS jobs  --> 工人
工人 --(紙條)--> SQS results --> 本機
```

## 為什麼現在不准開

專案閘門 **★G2**＝「工人在這台 Mac 上（含 Docker）已經跑通，產品負責人才准開 EC2」。

## 以後會開哪一種（先記起來）

| 項目 | 本專案決定 | 為什麼 |
|---|---|---|
| 區域 | 東京 `ap-northeast-1` | 全程單區 |
| 機型 | **`t4g.small`** | Arm（Graviton2）、2 vCPU／2 GiB。東京有賣 |
| 作業系統 | Amazon Linux 2023 **arm64** | 跟工人映像同一架構 |
| 進來的門（inbound） | **全部關掉**（連 22／SSH 都不開） | 工人不收連線 |
| 出去的門（outbound） | 開（要連 S3、SQS、ollama.com） | 否則拿不到工作 |
| 登入方式 | 以後用 SSM，不用金鑰檔、不開 22 | 現在不必建 key pair |
| 不要開的東西 | NAT Gateway、Elastic IP、負載平衡器、ECS／Fargate、Lambda | 貴或超出範圍 |

`t4g` 的 `g`＝Graviton＝**Arm**。不要選 `t3.small`（那是 x86）。映像若是 x86，這台機器跑不起來。

## 費用（2026-09-02 官方）

- `t4g.small` 有試用：每月最多 **750 小時免費**，至 **2026-12-31**；東京在名單內。超過或試用結束後改 On-Demand 計費。
- 試用**不含**超額 CPU credit。機器一直滿載會另外算錢。
- 本專案 Free plan 另有點數上限；開著忘關＝點數燒光＝關帳。
- 以後真的開了：不用時 `stop-instances`（硬碟還在、少扣運算）；不要的話 `terminate-instances`（整台刪掉）。

官方機型：<https://aws.amazon.com/ec2/instance-types/t4/>  
官方 FAQ（試用規則）：<https://aws.amazon.com/ec2/faqs/>

## Console 認路（只看，不要 Launch）

1. 右上角區域切 **東京**。
2. 開 <https://console.aws.amazon.com/ec2/>。
3. 左邊 **Instances**。現在清單應該是空的——**保持空的**。
4. 若你好奇按了 Launch instance，看到這些就關掉視窗、不要按 Launch：
   - Name
   - AMI：Amazon Linux 2023（**64-bit Arm**）
   - Instance type：`t4g.small`（不是 t3）
   - Key pair：以後才需要，現在不要建
   - Firewall：不要勾「Allow SSH / HTTP / HTTPS」

左邊還有 Security Groups、Elastic IPs。現在都不要新建。Phase 91 才會用 CLI 建「inbound 全空」的 security group，而且**仍然不開機**。

## 以後真的要開時（現在不要跑）

產品負責人明示 G2 之後，才會用類似下面的指令（完整參數在 Phase 92，這裡只讓你認得長相）：

```bash
# 現在不要執行
aws ec2 run-instances \
  --instance-type t4g.small \
  --region ap-northeast-1 \
  --profile personaldocai-admin
```

開錯了立刻停：

```bash
aws ec2 describe-instances \
  --profile personaldocai-admin --region ap-northeast-1 \
  --query 'Reservations[].Instances[].[InstanceId,State.Name,InstanceType]' \
  --output table
```

有任何 `running` / `pending` 的 `t4g` 或別的機型：

```bash
aws ec2 terminate-instances --instance-ids i-開頭那串 \
  --profile personaldocai-admin --region ap-northeast-1
```

## 不要做

- 按 Launch instance、跑 `run-instances`
- 開 SSH（22）、開 80／443、「方便除錯先開一下」
- 選 t3／t2（x86）或比 `t4g.small` 更大的機型
- 配 Elastic IP、NAT Gateway、負載平衡器
- 為了省事把工人映像做成 x86
