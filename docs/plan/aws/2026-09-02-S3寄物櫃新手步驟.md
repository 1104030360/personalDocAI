# S3 寄物櫃新手步驟

給剛建好 IAM user、第一次建 S3 的人。做完＝東京有一個**私有** bucket，專案之後把圖暫時放進去。

**這份只建資源，不改產品碼。** 程式真正打 S3 是後面的 phase。

查證日期：2026-09-02。來源見文末。

---

## 這是什麼

S3（Simple Storage Service）＝ AWS 的物件儲存。本專案把它當**寄物櫃**，不是相簿、不是備份。

本機把圖放進去，遠端工人自己去拿；工人把看圖結果放回去，本機自己去拿。兩邊都不必開門互連。

正本永遠在這台 Mac 的 Postgres 與 `data/`。處理完就刪。

---

## 先確認

- 已做完 [開戶步驟](./2026-09-02-AWS開戶新手步驟.md)
- CLI 用 **`personaldocai-admin`**（人用、可建資源）
- Console 右上角區域是 **亞太（東京）`ap-northeast-1`**

```bash
aws sts get-caller-identity --profile personaldocai-admin --region ap-northeast-1
```

要看到你的帳號 12 碼數字。記下來，後面要用**後六碼**當 bucket 名。

---

## 1. 算出名字並建桶

bucket 名**全世界唯一**。本專案格式：`personaldocai-mailbox-<帳號後六碼>`。

只能小寫、數字、`-`；**不能大寫、不能底線 `_`**。

東京一定要同時帶 `--region` 與 `LocationConstraint`。漏一個會建到美國，或直接報錯。

```bash
ACCOUNT_ID=$(aws sts get-caller-identity \
  --profile personaldocai-admin --query Account --output text)
S3_BUCKET="personaldocai-mailbox-$(printf %s "$ACCOUNT_ID" | tail -c 6)"
echo "$S3_BUCKET"

aws s3api create-bucket \
  --bucket "$S3_BUCKET" \
  --profile personaldocai-admin \
  --region ap-northeast-1 \
  --create-bucket-configuration LocationConstraint=ap-northeast-1
```

成功會印一行 `Location`。

常見錯：

| 訊息 | 意思 | 怎麼辦 |
|---|---|---|
| `IllegalLocationConstraintException` | 漏了 `LocationConstraint`，或 `--region` 不是東京 | 照上面整條重跑（什麼都還沒建好） |
| `BucketAlreadyExists` | 這名字全世界有人用了 | 改成 `personaldocai-mailbox-<後六碼>-tw` 再試 |
| `BucketAlreadyOwnedByYou` | **你已經建過了** | 不要再建，往下一步檢查 |

## 2. 鎖公開、確認加密

2023 年起，**新 bucket 預設**已是：

- Block Public Access 四項全開
- 預設加密 SSE-S3（AES256，免費）

仍要明寫一次，避免之後有人在 Console 改掉。

```bash
aws s3api put-public-access-block \
  --bucket "$S3_BUCKET" \
  --profile personaldocai-admin \
  --region ap-northeast-1 \
  --public-access-block-configuration \
    BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true

aws s3api put-bucket-encryption \
  --bucket "$S3_BUCKET" \
  --profile personaldocai-admin \
  --region ap-northeast-1 \
  --server-side-encryption-configuration \
    '{"Rules": [{"ApplyServerSideEncryptionByDefault": {"SSEAlgorithm": "AES256"}}]}'
```

兩條成功都**沒有輸出**。

**不要選 SSE-KMS。** KMS 自管金鑰每月要錢；本專案已否決。

---

## 3. 掃把：`documents/` 放超過 2 天就刪

正常流程處理完會自己刪。這條規則接住當機、工人掛掉留下的殘骸。

在專案根目錄建一個暫存 JSON（路徑可自訂）：

```json
{
  "Rules": [
    {
      "ID": "expire-documents-after-2-days",
      "Filter": { "Prefix": "documents/" },
      "Status": "Enabled",
      "Expiration": { "Days": 2 },
      "AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 1 }
    }
  ]
}
```

`AbortIncompleteMultipartUpload`＝傳到一半斷線留下的碎片。`list-objects` **看不到**它們，但會佔空間、扣點數。

```bash
aws s3api put-bucket-lifecycle-configuration \
  --bucket "$S3_BUCKET" \
  --profile personaldocai-admin \
  --region ap-northeast-1 \
  --lifecycle-configuration file://deploy/aws/s3-lifecycle.json
```

`file://` 後面是相對**你現在所在目錄**的路徑。不在專案根目錄就改用絕對路徑：`file:///完整路徑/s3-lifecycle.json`。

成功可能印 `TransitionDefaultMinimumObjectSize`（2024-09 之後的欄位）。本專案沒做儲存層轉換，看到即可。

## 4. 驗收（四條都要對）

```bash
aws s3api get-bucket-location \
  --bucket "$S3_BUCKET" --profile personaldocai-admin
# LocationConstraint 必須是 ap-northeast-1

aws s3api get-public-access-block \
  --bucket "$S3_BUCKET" --profile personaldocai-admin --region ap-northeast-1
# 四個欄位都是 true

aws s3api get-bucket-encryption \
  --bucket "$S3_BUCKET" --profile personaldocai-admin --region ap-northeast-1
# SSEAlgorithm 必須是 AES256，而且沒有 KMSMasterKeyID

aws s3api get-bucket-lifecycle-configuration \
  --bucket "$S3_BUCKET" --profile personaldocai-admin --region ap-northeast-1
# Prefix=documents/、Days=2、AbortIncompleteMultipartUpload=1
```

版本控制必須是關的（預設就是關，不要去開）：

```bash
aws s3api get-bucket-versioning \
  --bucket "$S3_BUCKET" --profile personaldocai-admin --region ap-northeast-1
# 空的，或 Status 不是 Enabled，都對
```

把名字記進 `.env`（只寫名字，現在還不必改程式）：

```
S3_BUCKET=personaldocai-mailbox-XXXXXX
AWS_REGION=ap-northeast-1
```

## 不要做

- 開版本控制、跨區複製、CloudFront、靜態網站託管
- 關 Block Public Access、加 `public-read`
- 選 SSE-KMS／自管金鑰
- 在這個 bucket 放正本照片或備份
- 現在開 EC2

---

## 做錯怎麼拆

桶是空的才能刪：

```bash
aws s3api delete-bucket \
  --bucket "$S3_BUCKET" \
  --profile personaldocai-admin \
  --region ap-northeast-1
```

裡面有東西先：`aws s3 rm s3://$S3_BUCKET --recursive --profile personaldocai-admin --region ap-northeast-1`
