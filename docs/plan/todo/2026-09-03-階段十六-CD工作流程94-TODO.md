- `if` 兩條件缺一不可：`workflow_run.event == 'push'`（擋 fork PR 觸發的 test）＋ `conclusion == 'success'`。
- `ref: head_sha`：部署 CI 真正測過的那一版，不是「當下的 main」。
- `platforms: linux/amd64,linux/arm64`：真機兩段都是 x86_64，漏掉 amd64 → EC2 `exec format error`（安靜壞在遠端）。
- 不填 `role-duration-seconds`（Phase 93 角色 max 3600）。
