## 實作邏輯

**PostgreSQL 策略（本階段最重要的決策）**：既有 @14 有其他專案資料庫，停用或替換它會破壞別的專案 → 採「**@17 並存於 5433 埠**」：

1. `brew install postgresql@17`，把它的 `postgresql.conf` 改成 `port = 5433` 再啟動——@14（5432）完全不受影響。
2. `~/.zshrc` 加 `PATH`（@17 的 bin 優先）＋ `export PGPORT=5433`——這樣後續所有 phase 文件裡不帶 `-p` 的 `psql`／`createdb` 指令**原樣可用**。
3. 副作用警示（要寫進文件）：互動終端機裡 `psql` 預設會連 5433（@17）；要連舊的 @14 請用 `psql -p 5432`。其他專案的**伺服器程式不受影響**（它們用自己的連線設定，不讀 zshrc）。
4. 所有 Python 連線字串明確帶 `:5433`（不依賴 PGPORT——IDE／服務啟動的程序不一定讀 zshrc）。
