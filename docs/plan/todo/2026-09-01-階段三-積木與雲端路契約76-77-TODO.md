**Phase 77 是契約與假件，還不碰 AWS。** 雲端路四件事（探測遠端、放 S3、發 jobs、等 results）每一件都會打 AWS；
直接寫 boto3 的話 78〜81 的每顆流程測試都得連網花錢。所以先訂契約：

```text
app/services/cloud_ingest.py（新；零 boto3）
  MailboxMessage / CloudMailbox Protocol（14 支：S3 三支、jobs 三支、results 四支、三個鍵名、instance_state）
  RemoteProbe Protocol / AlwaysRunning
  CloudRouteOff：available() 恆 False，其餘 raise RuntimeError("雲端路未啟用")
  build_context(PromptContext) -> dict（恰三鍵、可 json 序列化、不含位元組）
app/core/config.py             九個設定（CLOUD_ROUTE=off 預設、AWS_REGION、S3_BUCKET、兩條 SQS URL、EC2 兩個、逾時、WORKER_VERSION）
app/dependencies.py            get_cloud_route()：只認 off → CloudRouteOff()；assume／ec2 先 NotImplementedError
ingest_job_store.IngestJob     +privacy／+route 兩欄（total=False；create() 不預填；端點回應不變）
tests/fakes.py                 FakeMailbox（一顆假件＝S3＋兩條佇列＋流水帳 calls）、FakeProbe、ScriptedProbe、FakeCloudRoute
tests/conftest.py              第五道 autouse 安全網 wire_fake_cloud：CLOUD_ROUTE 蓋 off、get_cloud_route 雙管換 CloudRouteOff、AWS_ENDPOINT_URL 指死埠
```
